# Tesseract OCR Windows 64-bit Installer

Package repo for **Tesseract OCR v5.5.3 (64-bit)** setup for Windows.

## 📦 Included Files

- `tesseract-ocr-w64-setup-5.5.3.20260724.exe`: Official Windows 64-bit installer executable.
- `tesseract-ocr-w64-setup-5.5.3.20260724.zip`: Zip archive containing the installer.

## 🚀 Installation Instructions

1. Download `tesseract-ocr-w64-setup-5.5.3.20260724.exe` (or extract `tesseract-ocr-w64-setup-5.5.3.20260724.zip`).
2. Run the executable to install Tesseract OCR on your Windows machine.
3. Follow the setup wizard steps (select desired language data files during installation).
4. Add the installation path (typically `C:\Program Files\Tesseract-OCR`) to your System `PATH` environment variable.

## 🔍 Verification

Open Command Prompt or PowerShell and verify installation:

```cmd
tesseract --version
```
